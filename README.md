# Dragon-Arena
 Epic dragonball inspired Arena

## Install as an app
Open the game link on your phone, then Share > Add to Home Screen (iPhone) or the INSTALL APP button / browser menu (Android and desktop). It runs full screen, works offline, and updates itself whenever you are online.

## Ki Arena (public build)
Third-person arena battler with 8 original fighters, created by BaneBamage. One file: `ki-arena/index.html`.
Once GitHub Pages is on for this repo it plays at `https://auto-tech-pro.github.io/Dragon-Arena/ki-arena/`.
Online play (rooms, ranked, leaderboard) is built but switched off until the free relay in `ki-arena/relay/` is deployed. Offline modes (League, Quick Fight, Training, Tutorial) work now.
